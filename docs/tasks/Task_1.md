##### Overview

Pelajari seluruh arsitektur pada sistem tersebut terlebih dahulu lalu perhatikan game kedua (Garden Keeper), tolong perbaiki fitur untuk hand-tracking menggunakan MediaPipe sehingga dapat menggerakkan pointer yang berupa watering-can dimana Ketika diarahkan ke pot tertentu terdapat animasi menyiram air ke pot tersebut.



##### Target Terapeutik:

• shoulder flexion

• reaching

• kontrol Gerakan



##### Ketentuan :

* Jika tangan terbuka, maka melakukan penyiraman dengan syarat harus mendekati jangkauan / range pot
* Jika tangan tertutup, maka hanya berfungsi untuk mengarahkan pointer saja
