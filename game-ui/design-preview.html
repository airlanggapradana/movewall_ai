MoveWall AI
Design System v2.0

Pratinjau HTML interaktif dari seluruh token desain, tipografi, dan komponen v2.0. Bahasa visual SaaS modern terkini: Studio Terang & Gelap untuk Dashboard terapis, bento grid berhierarki klinis, palet grafik 4 seri, warna status koreksi crimson #9F1239 yang ramah buta warna (CIE76 14.0), tipografi Inter untuk dashboard dan Atkinson Hyperlegible Next untuk pasien, serta kanvas konten melayang ber-cincin 1 px dan bayangan berlapis.

Prinsip utama: Terbaca dari dua meter · Tidak pernah hanya warna · Aman lebih penting dari menang · Modern berarti hierarki dan kecepatan, bukan dekorasi
